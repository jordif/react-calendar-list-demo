# React Calendar List - Demo Website

This is the source code for the live demo of the React Calendar List component.

[🚀 View Live Demo](https://jordif.github.io/react-calendar-list-demo) | [📦 View Component on NPM](https://www.npmjs.com/package/@jordif/react-calendar-list) | [🐙 View on GitHub](https://github.com/jordif/react-calendar-list)

## About this demo

This project is built with Astro and React. It serves as a real-world example of how to use the React Calendar List component.

## Getting started

### 1. Clone the repository

```bash
git clone https://github.com/jordif/react-calendar-list-demo.git
cd react-calendar-list-demo
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The demo will be available at http://localhost:4321/
